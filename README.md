# number-guessing-game
this is my first ever repository

Welcome to my first Java project! This is a simple command-line game where the user tries to guess a randomly generated number between 0 and 100.

## Features
- Interactive console gameplay.
- Input validation to prevent crashes when letters are typed (`try-catch` exception handling).
- Play again loop to enjoy multiple rounds.

## How to Run
1. Open the project in IntelliJ IDEA or any Java IDE.
2. Compile and run `Main.java`.
3. Follow the on-screen prompts to start guessing!
